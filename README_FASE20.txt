MILK FASE 20 — COMMAND CENTER + AVATAR VIVO

Esta fase NÃO substitui as fases anteriores.
Ela cria uma interface desktop real para controlar e acompanhar a MILK.

NOVO
- Avatar MILK aparece no centro da tela.
- Efeito de brilho/pulsação para dar sensação de presença.
- Status da voz: pronta / ouvindo / entendeu / falando.
- Status do Whisper.
- Status da IA / 9Router.
- CPU, memória e disco em tempo real.
- Painel da memória SQLite.
- Painel de projetos.
- Git / GitHub / DevOps.
- Botão para abrir 9Router.
- Botão para abrir logs.
- Botão para abrir projetos.
- Botão para abrir memória.
- Botão para iniciar/parar a MILK.
- Console interno mostrando o que a MILK reconhece e responde.
- Entrada rápida para comandos básicos.

INSTALAÇÃO
1. Copie todo o conteúdo para C:\JARVIS e substitua.
2. NÃO apague:
   - Conversar_Com_MILK.py
   - .env
   - config\whisper_local.json
   - data\milk_memory.db
   - src das fases anteriores

3. Rode:
   C:\JARVIS\INSTALAR_FASE20.bat

4. Depois:
   C:\JARVIS\INICIAR_MILK_COMMAND_CENTER.bat

OU:
   cd C:\JARVIS
   python .\MILK_Command_Center.py
