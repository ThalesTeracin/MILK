FASE 6 - WAKE ONCE + WINDOWS AGENT ADMINISTRATIVO

COMPORTAMENTO NOVO:
1. Diga 'Jarvis' UMA VEZ.
2. Depois fale normalmente sem repetir o nome.
3. Diga 'dormir' para voltar ao SLEEP.
4. Para acordar novamente, diga 'Jarvis'.

TESTES:
- Jarvis
- abra a calculadora
- abra o bloco de notas
- abra o explorador
- como está o computador
- quais processos estão pesados na memória
- abrir powershell administrador
- abrir serviços
- dormir
